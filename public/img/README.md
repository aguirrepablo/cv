# Capturas de los proyectos

Guardá acá las capturas de cada sitio, con estos nombres exactos:

- `jojo.png`
- `nurtura.png`
- `segurarse.png`

Si alguna falta, el panel cae automáticamente a la miniatura dibujada en CSS
(no aparece el ícono de imagen rota). O sea que se puede publicar con las que haya.

## Recomendaciones

- Ancho máximo **1600 px**. Más que eso es peso al pedo: el panel nunca supera ~460 px.
- Se recortan a proporción **16:10** ancladas arriba, así que encuadrá pensando en el hero del sitio.
- Si alguna supera los ~200 KB, pasala por [Squoosh](https://squoosh.app) y exportá WebP.
  Si las convertís a `.webp`, actualizá la propiedad `image` en `src/data/projects.ts`.
